# Bricks

A brick is one capability of the system, at the level of a person who decides what to build next. The bricks go in a logical order, from the foundation up. Each status is true at the [snapshot](../README.md#snapshot), and the [status legend](../README.md#status-legend) defines each status.

## Add a brick

1. Add a brick only for a capability. A task or a fix is not a brick
2. Take the next free number
3. Put the row where the brick fits in the order
4. Create the file `B<nn>-<slug>.md`
5. Copy the sections of [B01](B01-durable-conversations.md) into it
6. Fill each section
7. For a planned brick, cite the source that states the plan. Without such a source, do not add the brick
8. Link to the decisions behind the brick, and to the docs that hold its mechanics
