# Principles

These rules shape every design choice in uao. Each principle links the decisions behind it. Principle 11 has no decision file yet, so it cites its commit.

1. **The conversation outlives the code.** A change goes live with no end to the conversation that made it. Put behavior in an extension when possible. Keep the supervisor tiny, and change it rarely (`AGENTS.md`). ([D001](decisions/D001-reload-by-layer.md), [D003](decisions/D003-supervisor-swap.md))
2. **Commit before you show.** State reaches SQLite before the UI shows it. A tool that runs again after a crash must do no harm, and an effect outside the transaction must accept a second run (`docs/durability.md`). ([D002](decisions/D002-pi-durable-sqlite.md))
3. **Pi is the role model.** Keep the code minimal, readable, and malleable. Prefer platform features and current dependencies, justify each new dependency, and pin the Pi packages to exact versions (`AGENTS.md`). ([D002](decisions/D002-pi-durable-sqlite.md), [D005](decisions/D005-codemode-sandbox.md))
4. **Each feature is an extension.** The core stays small. A feature lives in one extension folder that a user can replace or turn off. Extensions meet only through typed contracts, and the core tier depends only on itself. ([D004](decisions/D004-ui-from-extensions.md), [D007](decisions/D007-surfaces.md), [D024](decisions/D024-typed-contracts-core-tier.md), [D031](decisions/D031-resource-built-ins-off.md))
5. **One core, many projects.** The core is the same in every project. A project specializes it in its `.ultimate/` folder after the user trusts the project. A person adds personal pieces in `~/.ultimate/`. ([D006](decisions/D006-clone-apart-from-project.md), [D009](decisions/D009-trust-before-project-setup.md), [D018](decisions/D018-own-personal-layer.md), [D027](decisions/D027-project-code-through-branches.md))
6. **A team behind one agent.** The user talks to @ultimate. Coordinators own the judgment, subagents do bounded work, and standing agents keep what they learned. A branch is never a subagent. ([D013](decisions/D013-branch-is-not-subagent.md), [D019](decisions/D019-standing-agents.md), [D020](decisions/D020-size-the-work.md), [D022](decisions/D022-talk-to-ultimate.md))
7. **Isolate, then land green.** Parallel work happens in isolates. Only a submission that passes every check lands, and the top-level agent pushes it. ([D008](decisions/D008-worktree-per-conversation.md), [D010](decisions/D010-push-without-asking.md), [D011](decisions/D011-lander-queue.md))
8. **Ask before you build.** A question gets one proposal, and a feature gets an assessment. The build waits for the user's go. A small, clear instruction gets done at once. ([D017](decisions/D017-questions-get-proposals.md), [D025](decisions/D025-assess-first.md))
9. **Wake only when needed.** A note gives context and starts no turn. The system prompt stays the same between turns, so the provider cache holds. ([D021](decisions/D021-updates-are-notes.md), [D026](decisions/D026-stable-system-prompt.md))
10. **Remove what does not earn its place.** Everything stays on record, so the agent can see what works. A feature that adds nothing goes. No backward-compatibility shims or speculative fallbacks (`AGENTS.md`). ([D014](decisions/D014-remove-canvas.md), [D028](decisions/D028-cloud-only-backs-up.md), [D030](decisions/D030-previews-on-real-models.md))
11. **Rules about behavior live in prompts.** Prompts and agent definitions hold the rules about how agents behave. Code checks protect only against data loss, security problems, and impossible states. Lint enforces only what the user asked for (`AGENTS.md`, `6b8477d`)
12. **Design each visible result.** A result that a person sees gets a renderer that matches the existing cards. ([D012](decisions/D012-design-visible-results.md))
13. **Add, do not edit upstream.** uao keeps its own work where upstream does not edit, to decrease merge conflicts. Source: uao. ([D034](decisions/D034-follow-upstream.md))
