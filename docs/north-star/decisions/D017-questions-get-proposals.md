# D017 Explore questions, act on instructions

Decided 2026-10-17. Source: upstream. Status: active.

A question or a "how could we" gets an investigation and one proposal. Then the agent waits for the user's go. A clear instruction gets done at once. A delegated task and a scheduled run count as the go.

**Why.** A user who opens with a question usually wants to find a better approach first (`bf94a30`).

**Evidence.** `bf94a30` changes the principles of the prompt.
