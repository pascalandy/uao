# D016 Share Ultimate as a personal project

Decided 2026-10-17, revised 2026-10-29. Source: upstream. Status: active.

Ultimate remains a personal project shared as inspiration (`CONTRIBUTING.md`). Pull requests are welcome as shared ideas, but most remain unmerged (`5524835f`). A merge is an exception for a clear core fix or improvement (`5524835f`). Agents first adapt their project or personal setup (`5524835f`). Issues are not reviewed, and anything can change without a migration path (`CONTRIBUTING.md`).

**Why.** The commit gives no reason (`e445117`). The post says that "there are no guarantees about what stays and what changes" (section "Just Getting Started").

**Evidence.** `e445117` states the original policy. `465cf344` and `5524835f` revise it. Outside PR merges include `ba62f6c6`, `546cb645`, and `f05016b6`. These merges apply the core-improvement exception (inferred from their changes).
