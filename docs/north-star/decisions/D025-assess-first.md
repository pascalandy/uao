# D025 Assess a feature before building it

Decided 2026-10-19. Source: upstream. Status: active.

A feature, added functionality, or a question starts with one assessment from the coordinator. The assessment gives the complexity, the code delta, the reuse, a recommended approach, one easier alternative, the risks, and numbered decisions. A small, clear change goes straight to the build.

**Why.** The commit gives no reason (`f0d80a3`). The post shows the result: "an assessment and a questionnaire, five decisions with its own picks marked" (section "An Example: Side Chats").

**Evidence.** `f0d80a3`. `agents/coordinator.md` holds the assessment.
