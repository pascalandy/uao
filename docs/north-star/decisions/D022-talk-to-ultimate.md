# D022 Let the user talk only to @ultimate

Decided 2026-10-18. Source: upstream. Status: active.

The user talks to one agent, @ultimate, in its conversation. Messages for the user, questions, and branch results arrive there. The user does not create conversations or roots by hand (`AGENTS.md`).

**Why.** The commits say only that @ultimate is the place where the user talks (`4d3605e`, `eeae136`). The post says that "the only thing I need to pay attention to is my chat with Ultimate itself" (section "Notes").

**Rejected.** The Board surface, a feed with an inbox for all agents (`eeae136`). Manual creation of roots and branches (`1d2f700`).

**Evidence.** `4d3605e`, `eeae136`, and `cf96f4a`. [The work model](../../../AGENTS.md#how-work-is-organised-a-forest-of-conversation-trees) holds the rule.
