# D020 Size the work to the change

Decided 2026-10-17. Source: upstream. Status: active.

A coordinator makes a small, clear change itself. It edits, tests, commits, and submits. Substantive work keeps the full workflow with a plan, workers, and review.

**Why.** A live run sent a one-line command through the full workflow. The run took about 8 minutes and cost $0.94 (`25d180d`).

**Rejected.** The full workflow for every change (`25d180d`).

**Evidence.** `25d180d`. `agents/coordinator.md` holds the workflow.
